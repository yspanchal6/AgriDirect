# AgriLinker (AgroMarket) - Flutter frontend prototype

Frontend-only, local dummy data. No backend.

## Setup
1. `flutter create agrilinker` in an empty folder (generates android/ etc.)
2. Copy this zip's `lib/` and `pubspec.yaml` over the generated ones
3. `flutter pub get && flutter run`
